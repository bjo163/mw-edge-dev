# Near-term roadmap

The roadmap follows repository milestones and issues. It intentionally contains no invented delivery dates.

## V0.2 — Platform Hardening

Current focus is deterministic CI/release automation, security workflow hardening, dependency policy, operational validation, repository governance, and production-facing documentation.

Authoritative work is tracked in the [V0.2 milestone](https://github.com/bjo163/mw-edge-dev/milestone/2) and its issues.

## V0.3 — Cloud & Extensibility

The next architecture phase is reserved for cloud adapters, stronger plugin supply-chain controls, and future extension isolation seams. These capabilities are not current MW Edge behavior.

Authoritative work is tracked in the [V0.3 milestone](https://github.com/bjo163/mw-edge-dev/milestone/3).

## V1.0 — Production

V1.0 is gated by the production readiness checklist rather than a date promise. See [issue #123](https://github.com/bjo163/mw-edge-dev/issues/123) and the [V1.0 milestone](https://github.com/bjo163/mw-edge-dev/milestone/4).

For a current-state view, use the [capability maturity matrix](maturity.md).
